# AI-car-simulation-NEAT
This project simulates self-driving cars using the NEAT (NeuroEvolution of Augmenting Topologies) algorithm and Pygame. The goal is to evolve neural networks to drive a car on different maps while avoiding obstacles. The simulation uses sensor data from the cars to make real-time decisions and adjust their movement accordingly.
# Files in the Repository
README.md: This file, providing an overview of the project.

car_img.png: An image file of the car sprite used in the simulation.

config.txt: Configuration file for the NEAT algorithm, containing settings and parameters.

map.png: An image file representing the map for the car simulation.

map1_test.py: Python script for testing the simulation on Map 1.

map2.png: Another map image file for a different simulation scenario.

map2_test.py: Python script for testing the simulation on Map 2.
